# Portifolio — Eliandra Neto

Bem-vinda(o)! Este repositório contém o portfólio pessoal de Eliandra Neto: uma página estática e elegante que descreve competências, projetos, formação e meios de contacto. O objetivo é apresentar trabalhos e experiência de forma clara, profissional e acessível.

--

**Principais características**

- Página única (single-page) com secções para: Sobre, Competências, Projectos, Formação, Idiomas e Contacto.
- Design leve e responsivo, com tipografia refinada e focada em legibilidade.
- Ícones e imagens inline (SVG) para melhor qualidade em qualquer resolução.
- Links para downloads de CV em PT/EN e ligações para GitHub / LinkedIn.

**Tecnologias**

- HTML5, CSS3 (estilos modernos e variáveis CSS).
- JavaScript minimal para interacções (efeito de reveal ao fazer scroll, cursor opcional).
- Recursos estáticos (SVGs, PDFs) prontos para servir a partir do próprio repositório.

**Estrutura do repositório (resumo)**

- `index.html` — página principal do portfólio.
- `style.css` — folhas de estilo (separadas) para a apresentação.
- `logo.svg`, `cv/` — recursos estáticos (logo, CVs em PDF).
